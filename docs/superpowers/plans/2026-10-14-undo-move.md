# Undo Move ("Quay lại") Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement a responsive "Quay lại" (Undo move) button in the Xiangqi Arena game room that rolls back the previous half-move, restores board pieces and turn, resets the timer, and posts a system chat message.

**Architecture:** MatchControls exposes `onUndoMove` and `canUndo` props controlling an instant-action button. In `ArenaPage`, a persistent `Position` instance and `undoHistory: Array<{ undo: MoveUndo; prevLastMove: { from: number; to: number } | null }>` stack track moves applied via `Position.applyMove()`. When clicked, `handleUndoMove()` invokes `Position.undoMove()`, restores `board`, `sideToMove`, and `lastMove`, clears piece selection, resets the 60s turn timer, and adds a system notification to ChatBox.

**Tech Stack:** Next.js 14, React 18, TypeScript, Tailwind CSS, Jest, React Testing Library, `@xiangqi-arena/xiangqi-core`.

**Spec:** `docs/superpowers/specs/2026-10-14-undo-move-design.md`

## Global Constraints
- Target node >= 20, pnpm package manager.
- Zero lint warnings/errors with ESLint and TypeScript strict mode.
- All existing tests in `@xiangqi-arena/xiangqi-core`, `@xiangqi-arena/server`, and `@xiangqi-arena/web` must remain green.
- No modal confirmation on clicking "Quay lại" — must execute immediately when enabled.
- Nút "Quay lại" must be disabled (`disabled={!canUndo}`) when `undoHistory` is empty.

    render(<ArenaPage />);

    expect(undoBtn).toBeDisabled();

    // Check system chat notification
    expect(screen.getByText(/Đã quay lại nước đi/i)).toBeInTheDocument();

    const undoBtn = screen.getByRole('button', { name: /Quay lại/i });

    fireEvent.click(screen.getByTestId('piece-64'));

- [ ] **Step 3: Implement state and handlers in `apps/web/app/page.tsx`**

1. Import `MoveUndo` from `@xiangqi-arena/xiangqi-core`.
2. Define interface:
   ```typescript
   interface UndoRecord {
     undo: MoveUndo;
     prevLastMove: { from: number; to: number } | null;
   }
   ```
3. Initialize `position`:
   ```typescript
   const [position, setPosition] = useState<Position>(() => Position.initial());
   const [undoHistory, setUndoHistory] = useState<UndoRecord[]>([]);
   ```
4. In `handleSquareClick`:
   ```typescript
   const move = { from: selectedSquare, to: sq };
   const undoInfo = position.applyMove(move);
   setUndoHistory((prev) => [...prev, { undo: undoInfo, prevLastMove: lastMove }]);
   setBoard([...position.board]);
   setLastMove(move);
   setSelectedSquare(null);

   const nextSide = position.sideToMove;
   setSideToMove(nextSide);
   if (nextSide === 'r') {
     setRedTimer(60);
   } else {
     setBlackTimer(60);
   }
   ```
5. Implement `handleUndoMove`:
   ```typescript
   const handleUndoMove = () => {
     if (undoHistory.length === 0) return;

     const nextHistory = [...undoHistory];
     const lastRecord = nextHistory.pop()!;
     position.undoMove(lastRecord.undo);

     setUndoHistory(nextHistory);
     setBoard([...position.board]);
     setSideToMove(position.sideToMove);
     setLastMove(lastRecord.prevLastMove);
     setSelectedSquare(null);

     if (position.sideToMove === 'r') {
       setRedTimer(60);
     } else {
       setBlackTimer(60);
     }

     handleSendMessage('Đã quay lại nước đi.');
   };
   ```
6. In `handleConfirmNewGame`:
   ```typescript
   const newPos = Position.initial();
   setPosition(newPos);
   setBoard([...newPos.board]);
   setSideToMove('r');
   setSelectedSquare(null);
   setLastMove(null);
   setRedTimer(60);
   setBlackTimer(60);
   setUndoHistory([]);
   handleCloseModal();
   ```
7. Pass `onUndoMove={handleUndoMove}` and `canUndo={undoHistory.length > 0}` to `<MatchControls />`.
